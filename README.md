# Supermarket Management System 

A Java-based supermarket inventory management application developed as my first Data Structures and Algorithms assignment.

## Demo



## Overview

The system is designed to manage supermarket inventory across multiple floor areas, aisles, and shelves using custom-built data structures.

The project focuses on implementing data structures from scratch and applying object-oriented programming principles to a practical inventory management system.

## Features

* Manage floor areas, aisles, shelves, and products.
* Add, update, search, and remove inventory items.
* Track product quantities and calculate inventory values.
* Organise products according to their storage requirements.
* Automatically identify suitable product storage locations.
* Save and load inventory data.

## Technologies

* Java
* JavaFX
* Object-Oriented Programming (OOP)
* Custom Linked Lists and Abstract Data Types (ADTs)
* JUnit
